# Hardware and test reports

Store sanitized hardware and test evidence here using the templates in `../templates/`.

Before committing a report:

- remove serial numbers and Windows user names;
- remove private filesystem paths;
- do not commit raw vendor logs containing unrelated personal data;
- include the application commit, profile revision, BIOS version, and backend version;
- retain raw dumps privately when they contain identifying data;
- link the sanitized report from the relevant issue or decision record.

The directory is intentionally empty until Phase 0 is performed on the actual target laptop.
